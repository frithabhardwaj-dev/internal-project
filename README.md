# internal-project

Fritha Sharma's internal-assessment portfolio website.

The complete site is in `beginner-portfolio/`. It includes the personalised portfolio, project search and filtering, light/dark mode, project links, profile photo, and API-based chatbot integration.

Run locally from `beginner-portfolio/` with:

```text
node --env-file=.env.local dev.js
```

Never commit `.env.local`; it contains the private chatbot API key.
